# Festie 전시 웹사이트 (아이패드용)

졸업전시 아이패드에 띄워 두는 Festie 소개 사이트예요. 책상 위 물건(모니터 · 코르크보드 · 다이어리 · 핸드폰)을 손가락으로 누르면 기능 소개 팝업이 열려요. 핸드폰을 누르면 프로토타입 v13을 그 자리에서 직접 써볼 수 있어요.

- 화면 비율: 아이패드 프로 가로(4:3). 11형처럼 조금 더 넓은 화면에서는 양옆으로 벽과 책상이 자연스럽게 이어져요.
- 팝업 속 앱 화면 12장: 프로토타입 v13(최종) 기준

## 올리는 위치

zip 안의 `festie-site` 폴더와 `sw.js` 파일을 `festie-v4` 저장소 맨 위에 올려 주세요. `festie-site`는 기존 폴더를 덮어써요.

```
festie-v4/
├─ sw.js                  ← 오프라인 저장용 (꼭 맨 위에)
├─ festie-prototype-v13/
├─ festie-site/           ← 이 폴더
└─ festie-loop/           (아이맥 루프, 올렸다면 같이 오프라인 저장돼요)
```

주소: https://heewonheo.github.io/festie-v4/festie-site/

## 아이패드에서 띄우기

1. 아이패드 Safari에서 위 주소를 열어요.
2. 공유 버튼 › **홈 화면에 추가**를 눌러요. 홈 화면에 Festie 아이콘이 생겨요.
3. 홈 화면의 Festie 아이콘으로 열어요. 주소창 없이 전체 화면으로 열려요.
4. 처음 열면 오른쪽 아래에 '오프라인 준비 중 n/79'가 떠요. **'오프라인 준비 완료'**가 뜰 때까지 인터넷에 연결된 채로 기다려요(보통 몇십 초).
5. 비행기 모드를 켜고 다시 열어 보세요. 그대로 열리면 준비 끝이에요.

## 전시 중 설정

- 제어 센터에서 **화면 회전 잠금**을 켜고 가로로 둬요.
- 설정 › 디스플레이 및 밝기 › 자동 잠금 › **안 함**
- 설정 › 손쉬운 사용 › **사용법 유도된 접근**을 켜고, Festie를 연 상태에서 측면 버튼을 세 번 눌러 시작해요. 관람객이 다른 앱으로 나가지 못해요. 끝낼 때는 다시 세 번 누르고 암호를 입력해요.
- 90초 동안 아무도 만지지 않으면 팝업을 닫고 첫 화면으로 돌아가요. 시간은 `index.html`의 `IDLE_MS`에서 바꿀 수 있어요.

## 알아둘 것

- 오프라인 저장은 Safari와 홈 화면 앱이 따로 해요. 전시 때 쓸 쪽(홈 화면 앱)으로 한 번 열어서 '준비 완료'를 확인해 주세요.
- 인터넷이 연결돼 있으면 열 때마다 최신 파일을 먼저 받아와요. 깃허브에서 파일을 고쳤다면 인터넷이 될 때 한 번 열어 주면 저장본도 바뀌어요.
- 프로토타입 버전을 바꿀 때는 `index.html`의 `../festie-prototype-v13/`과 `sw.js`의 목록을 같이 바꿔야 해요.
- 관람객 폰용 QR(`qr.png`)은 v13 주소예요.
