# Festie 전시 웹사이트

졸업전시용 Festie 소개 사이트예요. 책상 위 물건(모니터 · 코르크보드 · 다이어리 · 핸드폰)을 누르면 기능 소개 팝업이 열리고, 핸드폰을 누르면 프로토타입 v12를 그 자리에서 직접 써볼 수 있어요.

## 올리는 위치

`festie-v4` 저장소 맨 위에 이 폴더(`festie-site`)를 그대로 올려 주세요. `festie-prototype-v12` 폴더와 나란히 있어야 해요.

```
festie-v4/
├─ festie-prototype-v12/
└─ festie-site/      ← 이 폴더
   ├─ index.html
   ├─ qr.png
   ├─ shots/         (팝업 속 앱 화면 12장)
   └─ fonts/         (폰트 9개, 인터넷 없이도 보이게)
```

주소: https://heewonheo.github.io/festie-v4/festie-site/

## 아이맥에서 띄우기

1. 크롬으로 위 주소를 열고 전체 화면(⌃⌘F)으로 바꿔요. 브라우저 확대는 100%로 두세요.
2. 시스템 설정에서 디스플레이 잠자기와 화면 보호기를 꺼 두세요.
3. 주소창까지 숨기고 싶으면 터미널에서 키오스크 모드로 열어요. 끌 때는 ⌘Q를 눌러요.
   ```
   open -a "Google Chrome" --args --kiosk https://heewonheo.github.io/festie-v4/festie-site/
   ```

## 인터넷이 없을 때

폰트와 QR은 폴더 안에 있어서 인터넷이 없어도 보여요. 프로토타입도 `../festie-prototype-v12/`에서 불러오기 때문에, 저장소 전체를 아이맥에 받아 두면 오프라인으로도 돌아가요.

- 이때는 `festie-site/index.html`을 크롬으로 직접 열면 돼요.
- 다만 파일로 직접 열면 상태바 색이 앱 화면 색을 따라가지 않고 검정으로 고정돼요.

## 들어 있는 동작

- 90초 동안 아무도 만지지 않으면 팝업을 닫고 첫 화면으로 돌아가요. 프로토타입을 쓰는 중에는 돌아가지 않아요. 시간은 `index.html`의 `IDLE_MS`에서 바꿀 수 있어요.
- 준비 팝업을 닫으면 책상 위 핸드폰에 D-DAY 알림이 떠요.
- '직접 해보기' 팝업의 '처음부터 다시' 버튼을 누르면 프로토타입이 시작 화면으로 돌아가요.
- QR은 관람객이 자기 폰으로 v12를 여는 주소예요.
