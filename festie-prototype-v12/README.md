# Festie 프로토타입

> 페스티벌의 모든 순간, 너의 옆에 있을게
> Your festival bestie, from discovery to memory

페스티벌 준비부터 기억까지 한곳에 담는 아카이브 앱 **Festie**의 인터랙티브 프로토타입입니다.
시작 화면 → 취향 고르기 → 탐색 → 준비하기(타임테이블 · 플레이리스트 · 체크리스트 · 티켓 QR) → 공연 당일 → 기록(리포트) → MY까지 처음부터 끝까지 직접 눌러볼 수 있어요.
내 타임테이블에서는 부가 기능 **친구와 함께**(링크로 타임테이블 주고받기)도 이어서 써볼 수 있어요.

ICT융합디자인과 졸업작품 · 2026

## 바로 보기

- **로컬**: `index.html`을 브라우저로 열면 바로 실행돼요. 서버나 설치가 필요 없어요.
- **GitHub Pages**: 저장소의 Settings → Pages에서 Branch를 `main` / `(root)`로 지정하면 `https://<아이디>.github.io/<저장소이름>/` 주소로 열려요.

넓은 화면에서는 가운데 폰 화면 옆에 **화면 바로가기**(드롭다운), **처음부터 다시 하기**, 휴대폰으로 여는 **QR 코드**만 보여요.
휴대폰으로 열면 앱이 화면 전체에 꽉 차게 보여요. 홈 화면에 추가하면 Festie 로고 아이콘으로 앱처럼 열려요. 이때는 화면 속 가짜 상태바(9:41 · 배터리)를 숨기고 휴대폰의 실제 상태바를 그대로 쓰며, 상단 색도 지금 화면 배경색에 맞춰 바뀌어요.

## 반영된 내용 (2026-11-02 기준 · v11 최종)

- **친구와 함께 (부가 기능)** 을 앱 프로토타입 안에 합침 — 따로 있던 친구 페이지 대신, 준비 › 내 타임테이블에서 바로 이어져요
  - 내 타임테이블 위쪽은 그대로 두고, 동선 카드 아래에만 '친구와 타임테이블 주고받기' 한 줄 버튼
  - 내 타임테이블 보내기: 링크 미리보기(일차별 팀 수 · 링크 주소 · 링크 복사) → 카카오톡으로 보내기 / 다른 앱으로 보내기
  - 친구가 보낸 링크 열기: 친구 이름 정하기 + '나와 같이 보는 무대 N팀'(일차별 한 줄) → 친구 타임테이블 추가
  - 친구가 생기면 내 동선 무대에 '민지와 함께' 글자 칩, 카드 아래 '함께 가는 친구' 목록(이름 · 같이 보는 무대 N팀)
  - 친구 이름을 누르면 '민지의 타임테이블' — 내 타임테이블과 같은 화면. 무대마다 '나도 봐요' / '+ 나도 담기' / '나는 이 시간에 ○○를 봐요', 맨 아래 받은 날짜 + '새 링크로 업데이트 · 빼기'
  - 로그인 없이 링크로 주고받고, 친구 이름과 타임테이블은 이 기기에만 저장돼요
- 타임테이블: 처음 고를 때 '어느 날 가나요?'(1일차만 · 2일차만 · 이틀 다)를 먼저 고르고, 가는 날만 탭으로 보여요
- 화면 전환 · 버튼 · 시트 · 토스트에 부드러운 모션 (기기에서 '동작 줄이기'를 켜면 모션 없이 보여요)
- 화면 바로가기 번호를 디자인 캔버스 '화면 전체'와 같은 순서로 맞춤 (0 시작 → 1 탐색 → 2 준비 → 3 기록 → 4 MY → 5 친구와 함께)

  - 시작 화면을 **컨페티**로 확정: 검정 바탕에 별 · 리본 · 점이 살랑이며 흩날리고, 로고와 카피는 가운데보다 살짝 아래. 기기에서 '동작 줄이기'를 켜면 정지 화면으로 보여요
  - 취향 고르기: 상단을 실제 festie 로고로, 배경 별을 화면 전체에 고르게, 고른 아티스트에 검정 스파크 표시
  - 하단 탭 바 아이콘 새로 확정 (꺼진 탭은 선, 선택한 탭은 면): 탐색 = 둥근 판 심볼 컷아웃 / 준비 = 집게가 심볼인 클립보드 / 기록 = 폴라로이드 / MY = 프로필 카드. 아이콘 28px, 레이블 12px
  - 색: 탐색 홈 로고와 '내 페스티벌' · '마이' 작은 제목 #9B76BF, '내 기록' #8F6A00, 기록 노랑 #FFFACD → #FFF7B8 (공유 카드 패턴도 같은 톤)
