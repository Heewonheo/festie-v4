# Festie 프로토타입

> 페스티벌의 모든 순간, 너의 옆에 있을게
> Your festival bestie, from discovery to memory

페스티벌 준비부터 기억까지 한곳에 담는 아카이브 앱 **Festie**의 인터랙티브 프로토타입입니다.
시작 화면 → 취향 고르기 → 탐색 → 준비하기(타임테이블 · 플레이리스트 · 체크리스트 · 티켓 QR) → 공연 당일 → 기록(리포트) → MY까지 처음부터 끝까지 직접 눌러볼 수 있어요.

ICT융합디자인과 졸업작품 · 2026

## 바로 보기

- **로컬**: `index.html`을 브라우저로 열면 바로 실행돼요. 서버나 설치가 필요 없어요.
- **GitHub Pages**: 저장소의 Settings → Pages에서 Branch를 `main` / `(root)`로 지정하면 `https://<아이디>.github.io/<저장소이름>/` 주소로 열려요.

넓은 화면에서는 폰 화면 옆에 **화면 바로가기** 메뉴가 보여요.
휴대폰으로 열면 앱이 화면 전체에 꽉 차게 보여요. 홈 화면에 추가하면 Festie 로고 아이콘으로 앱처럼 열려요. 이때는 화면 속 가짜 상태바(9:41 · 배터리)를 숨기고 휴대폰의 실제 상태바를 그대로 쓰며, 상단 색도 지금 화면 배경색에 맞춰 바뀌어요.

## 반영된 내용 (2026-10-21 기준)

- 브랜드 패턴 적용 (기존 레이아웃은 그대로, 패턴은 배경이나 카드 안에만)
  - 시작 화면: 블랙 패턴 전체 배경
  - 탐색 홈 · 취향 고르기: 라벤더 패턴을 상태바부터 타이틀 뒤까지
  - 공유 카드(9:16): 연노랑 패턴 카드 + 1:1 대표 사진
  - 공연 당일 · 티켓 꺼내기: 블랙 패턴을 은은하게
- 티켓 꺼내기: 양옆 반원 홈과 절취선이 있는 실제 티켓 모양
- 앱 아이콘에 Festie 로고 (탭 아이콘, 홈 화면 추가 아이콘, D-DAY 푸시 알림 아이콘)
- 준비 4가지를 모두 마치면 'D-DAY' 푸시 알림이 화면 위에서 내려오고, 누르면 공연 당일 모드로 들어가요
- 2차 교수님 피드백: 장르 칩 캐러셀 확장, 장소별 찾아보기 → 검색 화면, 포스터 D-day 축소, 검색 화면 전환 + 화면 키보드(한글 입력), 인기 검색어 1열, 내 타임테이블 수정하기 버튼 강조, MY → 준비하기 → MY로 돌아오기
- 새 화면: 시작 화면(로그인 없이), 취향 고르기, 알림, 공연 당일(D-DAY) 모드, 입장 QR 저장과 티켓 꺼내기, 여러 페스티벌 준비와 준비 그만두기, 음악 앱 처음 연결, 9:16 공유 카드, 기록이 쌓인 기록 홈, MY 하위 화면(프로필 · 찜한 아티스트 · 알림 설정 · 음악 앱 · 설정)
- 화면 안 아이콘 5종(별점 · 장소 핀 · 티켓 · 자물쇠 · 빈 상태 달력)에 심볼 적용

- 하단 내비게이션 아이콘에 Festie 스파크 심볼 적용 (탐색 · 준비 · 기록)
- 기록(리포트)은 타임테이블 · 플레이리스트 · 티켓을 마치면 열림. 체크리스트는 다 챙기지 않아도 됨
- 내 준비 한눈에: 티켓 칸 중복 정보 정리, "설정 완료" 칩을 타이틀 옆으로
- 그 밖의 교수님 피드백 반영 사항 (장르 칩, 검색, 페스티벌 상세 한글화, 타임테이블 일차별 담기, 리포트 수정 등)

## 폴더 구조

```
index.html            화면 마크업(<template>) + 실행 코드
js/festie-app.js      화면 상태와 동작 (탭 이동, 타임테이블 담기, 리포트 작성 등)
js/dc-lite.js         화면 마크업을 그려주는 작은 런타임
vendor/preact.umd.js  Preact 10 (MIT, vendor/PREACT-LICENSE)
assets/images/
  posters/            페스티벌 포스터
  artists/            아티스트 사진
  photos/             리포트용 현장 사진
  patterns/           브랜드 패턴 (SVG)
icons/                앱 아이콘 (Festie 로고)
manifest.webmanifest  홈 화면 추가용 정보
```

## 참고

- 프로토타입이라 입력한 내용은 새로고침하면 처음 상태로 돌아가요.
- 포스터 · 아티스트 · 현장 사진은 시연용 이미지예요. 공개 저장소에 올릴 때는 이미지 사용 권한을 한 번 확인해 주세요.
